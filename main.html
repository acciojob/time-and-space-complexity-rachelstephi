Time, Space, Complexity

Time complexity measures how the runtime of an algorithm increases as the size of the input data ($n$) grows. It doesn't clock actual seconds (since computers vary in speed), but instead counts the number of operations executed.High Efficiency: The algorithm stays fast even when handling massive amounts of data. Low Efficiency: The algorithm slows down drastically or crashes as input data grows.

Space complexity measures how much extra memory (RAM) an algorithm needs to run as the input data size (n) grows.Just like time complexity, it isn't measured in megabytes, but in the number of memory slots or variables allocated relative to the input size. O(n) describes a direct, one-to-one relationship between the size of your data and the resources used. If your data triples, your resource usage triples.
